## 需求描述

### 背景

dw 已审查 AutoFlow-dev 仓库（基于 v1.5.8）的代码，确认以下修复有价值，需合并回主仓库：

1. **c5b1081 — asyncio.to_thread 性能改造**：webui.py 中 20+ 处同步 `gw.*` 调用阻塞事件循环，单个慢请求（e2e 闸门、部署）会卡住所有并发请求包括健康检查。需改为 `await asyncio.to_thread(gw.func, args)`。
2. **c5b1081 — M7 安全修复**：`_bootstrap_webui_token` 不再把 token 明文打印到 stdout（日志泄露 = 控制面失陷），只显示文件路径；token 文件 chmod 0600。
3. **84a12fc — JSON 截断处理**：gateway.py 实体解析时跳过带 `__truncated__` 标记的截断 JSON；schema_block 阶段返回增加 `would_block_on_schema: True` 标记。
4. **83ffaea — 前端 XSS + 移动端修复**：
   - BUG-2：PWA standalone 模式下原生 `confirm()`/`prompt()` 无效，改用自定义 modal
   - BUG-3：`navigator.clipboard` 在 HTTP 下不可用，增加 `execCommand('copy')` 降级
   - BUG-4：iOS Safari textarea <16px 自动缩放，改为 16px + touch-target 44px
   - BUG-5：`esc()` 增加单引号 `'` 转义，防止内联 style XSS

### 目标

基于主仓库 **main 分支最新代码（v2.0.1-alpha，commit e63ae3d）** 重新实现上述修复，提交 PR 到主仓库。

### 范围

**包含：**
- 上述 4 项修复的完整实现
- 对应的单元测试（参考 AutoFlow-dev 的 tests/test_concurrent_to_thread.py、test_api_keys_expiry.py 等）
- 确保不破坏主仓库已有的竞技场（arena.py）、经验复用（experience.py）、Pro API（/api/core/*）等新功能

**不包含：**
- P0 api_keys 永不过期修复（dw 已自行修复，v2.0.1-alpha 已包含）
- Docker 非 root / 只读文件系统（主仓库容器配置不同，暂不做）
- 多 Agent 身份管理（主仓库已有 API Key 体系，不重复）
- Flow 一键回滚（主仓库已有 /api/core/rollback）

## 验收标准

> 必须全部满足才能合并到 main。

- [ ] **asyncio.to_thread**：webui.py 中所有调用 `gw.*` 阻塞方法的 async handler 均已用 `await asyncio.to_thread()` 包裹，包括但不限于：propose_dsl、deploy_proposal、deploy_raw、list_entities、resolve_entity、list_pending、approve、reject、plan_view、plan_update、nr_tabs、diagnostics、catalog_view/import、debug_read
- [ ] **M7 安全**：`_bootstrap_webui_token` 不打印 token 明文到 stdout，token 文件权限 0600
- [ ] **JSON 截断**：gateway.py 实体解析跳过 `__truncated__` 标记；schema_block 返回含 `would_block_on_schema`
- [ ] **前端 XSS**：`esc()` 转义单引号；token stats 等内联 style 属性用 `esc()`
- [ ] **移动端**：textarea/input/select 移动端 16px；自定义 modal 替代高风险 confirm()；clipboard 降级
- [ ] **测试标准**：asyncio.to_thread 并发测试通过；XSS 转义测试通过；现有全部测试不回归
- [ ] **兼容标准**：竞技场 API（/api/arena/*）、经验复用 API（/api/experience/*）、Pro API（/api/core/*）均正常工作
- [ ] **安全标准**：无新增安全漏洞，无硬编码密钥
