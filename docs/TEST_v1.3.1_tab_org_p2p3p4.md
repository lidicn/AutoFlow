## 测试用例

### P2-1：per_flow → single_tab 迁移

**前置条件**：当前有 2-3 个 per_flow 模式的 flow（每个 flow 独立 tab）

**步骤**：
1. 打开 WebUI → 设置 → 高级设置
2. 记录当前"独立 tab 模式"和"单 tab 模式"的 flow 数量
3. 点击"迁移到单 tab 模式"按钮
4. 确认迁移对话框
5. 等待迁移完成

**预期结果**：
- [ ] 迁移成功，显示成功数量
- [ ] 所有原独立 tab 的 flow 合并到「AutoFlow」tab
- [ ] 每个 flow 有 AF_START/AF_END 边界 comment
- [ ] 每个 flow 坐标区域不重叠
- [ ] 原独立 tab 被删除
- [ ] flow_catalog 中 tab_org_mode 更新为 single_tab
- [ ] 每个 flow 功能正常（触发 inject 能看到 debug 输出）

## 已知限制

1. P4 混合模式目前只能通过 API/MCP 指定 target_tab，WebUI 部署界面暂未增加目标 tab 选择器（后续版本补充）
2. 迁移过程中 Node-RED 可能短暂不可用，建议在低峰期执行
3. 迁移前务必备份 Node-RED flows
